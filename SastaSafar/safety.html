⚠️ Academic Demonstration & Security Notice (MCA College Project)

Sasta Safar is an academic prototype built using HTML, CSS, and Vanilla JavaScript with browser LocalStorage. Emergency SOS options utilize standard telephone protocols (tel:112) that launch your device's dialler; web browsers cannot autonomously initiate phone calls. Trip sharing uses the Web Share API with clipboard fallback. In a production carpooling application, live GPS tracking, automated SOS dispatch, and identity verification require dedicated backend cloud services, encrypted databases, and government API integrations (DigiLocker / VAHAN).
